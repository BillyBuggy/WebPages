- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Can specify different note durations:

WN = Whole  Note    HN = Half    Note    QN = Quarter Note
EN = Eighth Note    SN = 1/16'th Note    TN = 1/32'th Note

  note( C, 4, WN )
  note( C, 4, HN )
  note( C, 4, EN )
  note( C, 4, QN )















- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Looping -- Playing some statements more than one time.

  for (;;) {                      // Forever
    note( C )
    note( A )
    note( F )
    note( G )
  }

  for ( n=1 ; n<=3 ; n=n+1 ) {    // 3 times
    note( C )
    note( A )
    note( F )
    note( G )
  }














- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Statements can be on one line.

  note(C); note(A); note(F); note(G)













- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Write a little song.

  for ( n=1 ; n<=2 ; n=n+1 ) {
    note(C); note(A); note(F); note(G)
    note(C); note(A); note(F); note(G)
    note(E); note(G); note(E); note(A)
    note(C); note(D); note(F); note(G)
  }












- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Functions: Avoid repetition

  void cfun () {
    note(C); note(A); note(F); note(G)
  }
  void efun () {
    note(E); note(G); note(E); note(G)
  }
  
  cfun()
  cfun()
  efun()
  cfun()













- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
All notes above were (by default) quarter notes and octave 4.

The following two lines play exactly the same notes:

  note(C);      note(A);      note(F);      note(G)
  note(C,4,QN); note(A,4,QN); note(F,4,QN); note(G,4,QN)

Variables: Avoid repetition, easy to change all.

  dur = QN

  note(C,4,QN);  note(A,4,QN);  note(F,4,QN);  note(G,4,QN)
  note(C,4,dur); note(A,4,dur); note(F,4,dur); note(G,4,dur)



  dur = EN
  note(C,4,dur); note(A,4,dur); note(F,4,dur); note(G,4,dur)

  dur = QN
  note(C,4,dur); note(A,4,dur); note(F,4,dur); note(G,4,dur)

  dur = HN
  note(C,4,dur); note(A,4,dur); note(F,4,dur); note(G,4,dur)














- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Arrays and Loops.

  mya = [ C, A, F, G ]

  note(C     );  note(A     );  note(F     );  note(G     )
  note(mya[0]);  note(mya[1]);  note(mya[2]);  note(mya[3])

Another way: using "loops"

  mya = [ C, A, F, G ]

  for( k=0 ; k<4 ; ++k )
    note( mya[k] )














- - - - - - - - - - - - - - - - - - - - - - - - - - - - - - -
Previous song using arrays and loops:

  Before: note(C); note(A); note(F); note(G)
          note(E); note(G); note(E); note(G)

  myC = [ C, A, F, G ]
  myE = [ E, G, E, G ]

  for( k=0 ; k<4 ; ++k )
    note( myC[k] )

  for( k=0 ; k<4 ; ++k )
    note( myE[k] )

If-Statements and Buttons:

English:
  If something is true then
    do something.

Programming
  if ( something_is_true ) {
    execute_some_statements
  }

                                              note(_,4,SN)

  }
